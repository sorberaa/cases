## 🚀 Як розгорнути на Render.com (Безкоштовно)

### Варіант А: Як Web Service на Python (Рекомендовано для повної роботи адмінки)
1. На Render натисніть **«New +»** ➔ **«Web Service»**.
2. Підключіть репозиторій `sorberaa/cases`.
3. Вкажіть:
   - **Environment:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python server.py`
4. Натисніть **«Create Web Service»**.
*(За бажанням, у розділі Environment Variables можна вказати власні `ADMIN_USER` та `ADMIN_PASS`)*.

### Варіант Б: Як Static Site
1. На Render натисніть **«New +»** ➔ **«Static Site»**.
2. Вкажіть Publish Directory: `.` (крапка).
3. Натисніть **«Create Static Site»**.
