## 🚀 Як розгорнути на Render.com (Безкоштовно)

Сайт оптимізовано для обох варіантів розгортання на Render:

### Варіант А: Як Static Site (Рекомендовано, 100% безкоштовно)
1. Завантажте файли проекту в новий репозиторій на GitHub.
2. Зайдіть на [dashboard.render.com](https://dashboard.render.com).
3. Натисніть **«New +»** ➔ **«Static Site»**.
4. Оберіть свій репозиторій.
5. У налаштуваннях вкажіть:
   - **Build Command:** *(залиште порожнім)*
   - **Publish Directory:** `.` *(крапка або public)*
6. Натисніть **«Create Static Site»**. Через 30 секунд ваш сайт буде доступний за посиланням на `.onrender.com`!

### Варіант Б: Як Web Service (Python)
1. Натисніть **«New +»** ➔ **«Web Service»**.
2. Вкажіть:
   - **Environment:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python server.py`
3. Натисніть **«Create Web Service»**.
